# Acceso de la página pública

La medición y la corrección están en `ui-audit` → `references/accessibility.md`. Aquí solo el mínimo para publicar.

## Texto alternativo y contraste

- Imagen que informa: alternativa que dice lo mismo que la imagen.
- Imagen decorativa: alternativa vacía.
- Texto normal al menos 4.5:1. Texto grande y componentes de interfaz al menos 3:1.
- El estado de error no puede depender solo del rojo.

## Formularios y botones

- Cada campo tiene etiqueta visible, asociada al control.
- Se puede completar y enviar solo con teclado. El foco se ve.
- El error dice qué corregir, junto al campo.
- El botón nombra la acción (“Crear cuenta”, “Pagar pedido”), no un “Enviar” suelto ni “Click aquí”.
