## Qué es HorizonX (análisis)

| Aspecto | Hallazgo |
|---------|----------|
| Producto | Biblioteca premium in-house de UI kits, landings, componentes, Figma y demos Code/WebGL/GSAP |
| Explore | ~88+ piezas curadas (Featured / Most viewed / Newest) |
| Categorías | UI/UX · Code · Vibe coding · Assets · Branding |
| Tier | Browse del catálogo usable como mood board; download Figma/código = suscripción (~$25–$100/mo) o compra unitaria |
| Licencia | Comercial incluida en plan (según FAQ del sitio) |
| Calidad | Curación propia (no marketplace anónimo); énfasis cinematográfico / product storytelling / dark SaaS |
