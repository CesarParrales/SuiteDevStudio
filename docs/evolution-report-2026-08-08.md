# Evolution report — 2026-08-08

Alta de **Animos** (`animos.app`) como referencia de carruseles / showcase motion.

## Qué es Animos (análisis)

| Aspecto | Hallazgo |
|---------|----------|
| Producto | Editor no-code en navegador: templates de motion looping para showcase de diseños |
| Templates | ~25 (card stacks, sliders, tilts 3D, cascadas) |
| Workflow | Pick template → drop images/videos → tweak → export MP4/WebM |
| Privacidad | Procesamiento local en cliente (según FAQ del producto) |
| Tier | Templates + 720p free; HD–8K Pro |
| Ratios | 16:9, 4:3, 1:1, 4:5, 9:16 |

## Clasificación en la suite

```
INSPIRACIÓN (default)  → patrones de ritmo/loop/perspectiva de carrusel
EXPORT                 → clips marketing / launch / portafolio
NO IMPLEMENTACIÓN      → no es Embla/Swiper; carrusel producto = código + a11y
```

Decisión de uso acordada: **inspiración + export clips** (no código de producto).
